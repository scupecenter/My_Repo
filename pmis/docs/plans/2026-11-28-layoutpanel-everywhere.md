# Layout panel on every remaining table screen (built)

The Layout panel (display options: size, alignment, density, wrap, zebra rows, group bar, reset, link to the organization defaults) now sits on every table screen. Columns stay in the column menu next to it, as on My Work, Sites and Archive.

Covered (new): Audit log, System log, Field changes log, and every screen built on `StandardTable` (Warehouse items, movements, stock and dispatch; Site documents, dismantle, activity, dispatch, applicability and master source tabs). Already covered before: Sites, Site (tasks), Daily plan, Library archive and media, Registers, My Work, Approvals.

Excluded: Dashboard, Messages and Inbox (cards and threads, not tables), Library forms (a list of cards with one search box, no columns), the registers' vertical layout (no table).

Settings: the panel's Display values follow the existing per-screen choice and the organization default (Settings > Screens > Tables); nothing new is stored. No migration.
