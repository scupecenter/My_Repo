# Standard toast and data-reset result dialog (2026-11-28)

Approved by Ahmed (relayed 9:46).

- Normal operation: toast at the bottom corner (right in English, left in Arabic via `end-4`), green check and text, gone after 4.5 s. Empty text shows "Done".
- Error: red, alert icon, stays until its close button is pressed (unless `opts.ms` is given).
- Data reset only: after the run commits, a centered dialog with a big check, rows deleted per part, sessions ended, files moved, and a Close button. No timer, no outside-click or Escape dismissal.
- Existing `useToast()` is reused, so every screen gets the behavior. No migration, no label.
