# P8: register column-lock row moves into the More menu
The loose row above every register table (column select, Column settings link, Lock button, one Unlock button per locked column) is gone. The register More menu now has: Lock a column (opens a small dialog with the column select, then the existing reason dialog), one Unlock entry per locked column, and Column settings for users who may edit columns (admins keep the existing Add column and Manage columns entries). Same hooks, same reason rule, same audit; the database still decides who may lock. Test ids: `register-column-lock`, `register-column-lock-select`, `register-column-lock-continue`, `register-column-unlock-<code>`, `register-columns-settings`.
