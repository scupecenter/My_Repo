# QR code per site

The site page has a QR icon button (next to Follow). It opens a sheet with the QR code, the site code, the English and Arabic names and the address in words. Print prints only the sheet (A4); Copy link copies the address.

- The code opens the ordinary site page (`/sites/<id>`). A signed-out phone goes to sign-in first and comes back (`?next=`). Scanning gives the rights the person already has; there is no new door and no token.
- Nothing is stored or sent: the code is drawn in the browser. No migration and no contract change.
- Not built: a separate field-capture entry. The site page already holds the photo, document and snag panels.
