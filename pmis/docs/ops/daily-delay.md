# Daily delay log

A daily delay is an issue of the type "Daily delay" in the Issues register. No new screen: it uses the register, so rights, search, filters, saved views, export, the audit of every save and the data reset plan apply as for any issue.

## How to record one
1. Open the Issues register and add an issue. Choose the category "Daily delay".
2. The site is the record's site. Set the Delay date (the day lost) and the Blocker reason.
3. If one task was stopped, write its code in "Blocked Gate / Task".

## Reasons
The reasons are the values of the list "Blocker reason". Edit them in Settings > Registers > Lists: add, rename (English and Arabic), reorder, merge or hide. A value is never deleted, so old records keep their reason. The first set: weather, access or permit, permit pending, material not delivered, delivery delay, team not available, safety stop, and others.

## Where it shows
- Dashboard issue card: the breakdown by category and by reason includes the delays.
- Register list and filters: Delay date, category and reason are columns and filters.
- Export: the register export carries the same columns.

## Notes
Additive migration 0554 (data only). Existing issues are not changed. Nothing is required, so an issue without a date or reason still saves.
