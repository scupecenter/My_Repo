# Site address through Change Control

The address of a site can be proposed for change, like the Arabic site name.

- In Site identity, "Propose a change" now has an Address field. Leave it as it is to keep the address; clear it to remove the address.
- Each changed field becomes its own Change Control draft. The site keeps its address until the approver decides.
- The address is at most 500 characters. Control characters are removed and spaces at both ends are trimmed. A text equal to the current address is refused as unchanged.
- A System Admin can also edit the address directly in the admin edit section, with a reason and a step-up, and the edit can be reverted like the other fields.
- Who may propose or approve the change is the same as for the names. Nothing about rights changed.
- Every applied change is audited with the old and the new address.
