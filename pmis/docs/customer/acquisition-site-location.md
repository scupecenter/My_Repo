# Site location from the selected acquisition candidate

When an acquisition candidate is marked as selected and has coordinates or an address, its record shows a "Site location" panel.

- If the site has no coordinates, the panel offers to propose the candidate's coordinates.
- If the site already has different coordinates, both are shown and the panel asks for confirmation before proposing the candidate's.
- If they match, the panel is not shown.

The site identity is never changed directly. The panel creates the same change proposal as the Site identity section, with a reason, and it follows the normal approval. Only users who may create or edit records see the panel. The candidate's address is proposed in the same request as its own draft, and only when it differs from the site's address.
