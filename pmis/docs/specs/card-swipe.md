# Swipe on cards

On a touch screen, a finger swipe on a board card:
- toward the end of the line (right in English, left in Arabic) runs the card's own main control (task board: open the task; site board: the card's action), only if that control is enabled;
- toward the start opens the standard context menu of the card.

Mouse and pen are never affected. Text fields are left alone. Vertical scrolling stays with the browser. Settings, Screens, Motion has the switch (default on, saved in this browser). No endpoint or migration; rights stay in the controls.
